傑出品 Navisworks Manage 2023 插件 — 1.3.1.0

在其他电脑上安装，无需 AI Agent、开发工具或修改默认路径：
1. 将 ZIP 完整解压到一个新文件夹，不要在压缩包内直接运行。
2. 关闭要更新的 Navisworks Manage 2023，双击“安装.bat”。
3. 窗口会读取这台电脑的注册表、快捷方式等，查找真实安装目录。
   多个安装时请选择目标；没有找到时点击“浏览”，选择该软件的
   Roamer.exe 或桌面快捷方式。也可粘贴完整安装目录。
   支持任意盘符、中文、空格。不要选择 ZIP 解压目录或 Exporters。
4. 如果包未签名，确认来源可信后勾选同意框，再点击“安装 / 更新”。
   Windows 请求管理员授权时允许，取消不会执行安装。
5. 下方显示“文件安装验证通过”后，启动 Navisworks，
   按下方“如何使用”走一遍，确认功能正常。

如何使用（在 Add-Ins 中点击“傑出品查找”，打开 Curi 窗口）：
1. 在选择树中选中要搜索的模型节点（通常是 TS-M 开头的根节点）。
2. 点击“导入 XML”或“＋ 添加”准备条件，双击任一行可修改。
3. 点击“执行搜索”。默认只选中匹配对象，不做隐藏。
4. 在“结果”页先处理“问题项”，再选择“创建选择集”、
   “隐藏未选中”或“导出结果”。
遇到问题点窗口右上角“？ 使用说明”。隐藏错了可在 Navisworks
“常用”→“全部显示”恢复。

桥架测量：
1. 点击 Curi 页头“桥架测量 ▾”，选择“便捷测量”或“批量测量”。
   “便捷测量”保留简易小窗口：选中一个构件，点击“测量选中构件”，
   查看大号长度及毫米换算；一次只测一个，无需导入，多选时会提示。
   小窗口可独立保留，也提供 Add-Ins“桥架便捷测量”入口。
   “批量测量”继续提供以下两种方式：
2. “批量导入查找”：导入桥架条件并执行搜索，确认“计入匹配”，
   返回测量窗口读取查找结果，再点击“开始批量测量”。
3. “手动点选构件”：无需导入，直接在模型或选择树中选中桥架，
   按 Ctrl 可多选，再点击“测量当前选择”。重新选择后再次点击测量即可更新。
4. 查看总长和逐件长度；双击行可定位，支持停止与导出 CSV。
   弯头、三通、不确定几何或父子层级重叠标为“待复核”，不计入总长。
   查找结果变化只影响批量模式；手动结果保留本次测量快照。
   切换测量方式会清空旧清单。实际模型精度与界面由用户核实。

只支持 Manage 2023 x64（API 20.x）。2021、Freedom、Simulate、
Exporters 不能使用本包。目标电脑需要原有的 Navisworks 安装环境。

“验证.bat”检查安装文件、哈希、依赖和加载布局。
“卸载.bat”可移除本插件。三者使用同一套路径发现和浏览选择功能。
成功操作后在当前用户本地配置目录记住路径，不会写入分发包。
操作日志位于窗口显示的 TEMP 独立目录，可将日志用于排错。

本版直接编译 navisworks-plugin 的当前源码，包含重复项批量计入。
文件名带 snapshot 表示工作区快照；PACKAGE_MANIFEST.json 中记录真实
Git 状态和输入哈希。哈希校验用于检测损坏，不能代替对来源的信任。
文件级验证通过不代表真实模型功能已验收，请完成安装第 5 步。
